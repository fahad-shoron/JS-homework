# JavaScript Homework

This repository contains solutions to JavaScript homework problems covering **Variables**, **Operators**, and **Conditional Statements**.

## 📁 Repository Structure

- `index.html` - Main HTML file connecting all script files.
- `qs1.js` - Question 1: Super Shop Bill Calculator
- `qs2.js` - Question 2: Ride Fare Calculator
- `qs3.js` - Question 3: Student Grade Calculator
- `qs4.js` - Question 4: Electricity Bill Calculator

## 🚀 How to Run

1. Clone or download this repository.
2. Open `index.html` in any web browser.
3. Open the **Browser Console** (F12 or Right Click -> Inspect -> Console) to see the output.
